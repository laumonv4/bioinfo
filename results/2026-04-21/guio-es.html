At4-families.fa

El archivo de salida más importante es At4-families.fa, ya que contiene las secuencias consenso de las familias de elementos repetitivos identificadas. Este archivo constituye la base para análisis posteriores, como la anotación de repeticiones en el genoma mediante herramientas como RepeatMasker.

En el archuivo llamado stk que es el alineamiento de estocolmo tendrá unas cuantas secuencias de familias alineadas para generar el consenso. Si representamos en diagramas de cajas los tipos de familias vemos que existen diferentes tipos de elementos disponibles que se recogen en RepeatModeler como por ejemplo loselementos LINEs o Los Gypsy.

GALBA

Para ejecutar GALBA ha sido necesario crear algunas variables de entorno que indican donde puede GALBA encontrar un par de ejecutables más. Para facilitar la reproducibilidad, este tipo de definiciones deben aparecer al principio del bloque, donde son más visibles, para que sean fácilmente modificadas cuando las órdenes vayan a ejecutarse en otro ordenador.

GALBA es un script de PEARL que está olvidad por la mayoría de personas pero todavía se puede utilizar. Ellos no se dan mucha importancia a si mismos porque piensan que hay programas mejor que ellos como BREAKER, antes que instalar GALBA2 instalaríamos SINGULARITI Para esto es muy posible que exista un programa de inteligencia Artificial como ALphaPhold parapredecir la estructura de proteinas.

export TSEBRA_PATH=/home/joiglu/bin/TSEBRA/bin/
export MINIPROTHINT_PATH=/home/joiglu/bin/miniprothint/

galba.pl --species="Arabidopsis thaliana" \
         --genome=At4.soft.fa \
         --prot_seq=proteinas.fasta
